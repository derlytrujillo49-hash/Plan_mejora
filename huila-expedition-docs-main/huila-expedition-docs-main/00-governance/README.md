## How governance applies

Governance rules apply to *the entire project* — all sections, all modules, all team members (Manuel, Luisa, Juan, and Natalia). If a rule conflicts with a local convention, governance wins unless a new Architecture Decision Record (ADR) overrides it.



> Change a governance rule only through team agreement. 
> Document the change and the reason. Announce it before the next sprint.
